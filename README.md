#MailMsgTag
'========================================================================
【ソフト名】　MailMsgTag for Outlook (Version 2026.11)
【著 作 者】　冨田 敏
【種　　別】　フリーソフトウェア (無料)
【動作環境】　Windows 10 / 11 (64bit / 32bit)
　　　　　　　Microsoft Outlook 2016 / 2019 / 2021 / Microsoft 365 (デスクトップ版)
　　　　　　　※本ソフトはOutlookの「COMアドイン」として動作します。
　　　　　　　※Microsoft Storeアプリ版・WEB版(新しいOutlook)には対応していません。
　　　　　　　.NET Framework 4.8 以上
'========================================================================
このソフトは、デスクトップ版のOutlookで動作するCOMアドインです。
複数のメールを、置換タグで日付,会社名などでフォルダを作り、指定したパスに
保存(エクスポート)できます。添付ファイルの保存、PDF,docx での保存も可能です。
保存先、書式は履歴ファイルに記録して、次回以降の設定作業を簡略化できます。
