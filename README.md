【動作環境】　Windows 10 / 11 (64bit / 32bit)<br>
　　　　　　　Microsoft Outlook 2016 / 2019 / 2021 / Microsoft 365 (デスクトップ版)<br>
　　　　　　　※本ソフトはOutlookの「COMアドイン」として動作します。<br>
　　　　　　　※Microsoft Storeアプリ版・WEB版(新しいOutlook)には対応していません。<br>
　　　　　　　.NET Framework 4.8 以上<br>
'========================================================================<br>
このソフトは、デスクトップ版のOutlookで動作するCOMアドインです。<br>
複数のメールを、置換タグで日付,会社名などでフォルダを作り、指定したパスに<br>
保存(エクスポート)できます。添付ファイルの保存、PDF,docx での保存も可能です。<br>
保存先,書式等は、履歴ファイルに記録されるので次回以降の設定が簡略化されます。<br>
